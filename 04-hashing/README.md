# Module 4 - Hashing

## Learn
Using `HashMap` and `HashSet` to turn repeated searches into constant-time lookups.

## Explain it in English
- What fact should be remembered?
- What is the key and what is its value?
- When do I check before inserting?
- What duplicate or missing case matters?
- Why does this avoid an inner loop?

## Practice
Convert one O(n^2) lookup problem into an O(n) map or set solution.

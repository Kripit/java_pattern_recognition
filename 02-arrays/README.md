# Module 2 - Arrays

## Learn
Traversal, prefix sums, Kadane's algorithm, and core array patterns.

## Explain it in English
- What does the current index represent?
- What information has already been calculated?
- Can a prefix or running answer avoid repeated work?
- When should the current range restart?
- What are the boundary indexes?

## Practice
Write a brute-force solution first, then improve it with a running state, prefix sum, or one-pass scan.

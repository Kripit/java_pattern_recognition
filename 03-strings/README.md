# Module 3 - Strings

## Learn
Immutability, `StringBuilder`, palindrome checks, and substring patterns.

## Explain it in English
- Am I comparing characters, building text, or counting characters?
- Do I need a new string or a mutable builder?
- Which two positions are being compared?
- What makes a substring valid?
- What happens with empty text or one character?

## Practice
Trace character indexes carefully and state whether a solution creates extra strings.
